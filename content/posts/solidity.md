# 스마트 컨트랙트 실행

- 스마트 컨트랙트에 저장된 데이터는 블록체인 네트워크에서 영구적으로 유지된다.
- 배포된 스마트 컨트랙트는 데이터를 저장하는 계정으로, 컨트랙트를 파기하지 않는 한 데이터는 영구적으로 보존된다.

## 솔리디티 코드 작성 및 배포


### 자바스크립트의 클래스와 인스턴스 생성


```javascript
class Counter{
	value : number;
	constructor(){}
	setValue(){}
	getValue(){}
}
```

1. 넘버타입인 value라는 속성과 3가지 함수를 가지고있는 Counter 클래스를 선언한다.

```javascript
const _counter = new Counter();
_counter.setValue(2);
_counter.value;
```

1. Counter클래스의 인스턴스를 _counter에 대입한다.
2. _counter인스턴스의 setValue 메서드를 호출하고 2라는 값을 인자로 전달한다
3. _counter의 value 속성 값을 반환한다. → 2

### 솔리디티 코드 작성 과정

1. 라이센스 정보 작성
2. 솔리디티 버전 명시
3. 컨트랙트 내용 작성
1. 자바스크립트의 클래스는 인스턴스를 생성하는 과정이 (new 키워드를 사용해서 만듬)
2. new 키워드를 통해 생성된 인스턴스들은 다른 메모리 공간을 가지고 있기에 주소가 다르기에 동일한 객체가 아니다.
3. 이후에 생성된 인스턴스를 CA 주소로 참조해서 컨트랙트를 조회하면 사용하는 데이터는 같은 데이터를 참조한다. (싱글톤 패턴)

### 스마트 컨트랙트 배포 프로세스

1. **컨트랙트 코드 작성 :** 스마트 컨트랙트의 로직을 정의한다.
2. **코드 컴파일 :** 작성된 코드를 EVM이 이해할 수 있는 바이너리 형태로 변환한다.
3. **트랜잭션 생성 및 전송 :** 컴파일된 코드와 함꼐 트랜잭션을 생성하고 네트워크에 전송한다.
4. **블록체인에 기록 :**  트랜잭션이 블록에 포함되어 처리되면, 컨트랙트주소가 생성되고 해당 주소에 코드가 저장된다.
5. **실행 및 상태 변경 :** 네트워크에 실행 메서드를 ABI형태로 요청을 보내면, EVM이 해당 메서드를 찾아 실행하고 상태변수를 변경한다.
