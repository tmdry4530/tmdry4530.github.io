# tsconfig.json


타입스크립트 컴파일러에게 프로젝트를 어떻게 컴파일 할지 알려주는 설정파일이다.


## 주로 사용되는 속성의 종류

- **compileOptions** : 컴파일러의 옵션을 설정하는 객체. 이 안에는 다양한 속성들이 포함된다.
- **target** : 컴파일된 코드의 ECMAScript버전을 지정한다.
    - ex) es5, es6등
- **module** : 생성된 모듈코드의 종류를 지정한다. ex) commonjs, amd, es2015등
- **lib** : 컴파일에 포함될 라이브러리 파일을 지정한다.
    - ex) dom, es2015등
- **outDir** : 컴파일된 파일이 출력될 디렉토리를 지정한다.
- **strict** :  모든 엄격한 타입 검사 옵션을 활성화한다.
- **esModuleInterop** :  ES 모듈과의 상호 운용성을 활성화
    - ex) CommonJS와 ES6형식의 혼용을 허용한다
- **allowJs** : 자바스크립트 파일의 컴파일을 허용한다.
- **checkJs** : 자바크스크립트 파일의 타입 오류를 검사한다.
- **declaration** : .d.ts선언 파일을 생성한다.
- **sourceMap** : 소스 맵을 생성한다. 이를 통해 디버깅 시 타입스크립트 코드를 직접 볼 수 있다.
- **include** : 컴파일에 포함될 파일 또는 디렉토리의 배열다.
- **exclude** : 컴파일에서 제외될 파일 또는 디렉토리의 배열이다.
- **extends** : 다른 tsconfig.json파일을 상속받는다.
- **files** : 컴파일에 포함될 파일의 목록이다.
- **baseUrl** : 모듈의 상대 경로를 기본 경로로 설정합니다. 일반적으로 './src'로 설정한다.
- **paths** : 'baseUrl'로 지정한 경로를 기준으로 상대 위치를 가져오는 매핑 값을 작성한다. 이를 통해 경로를 변수처럼 사용할 수 있다.
    - ex) “/@temp” “@user/*”

## 환경 설정시 주의사항

1. **경로 설정**
    1. include, exclude, files 등의 경로 설정은 프로젝트의 루트 디렉토리를 기준으로 한다.
    2. 절대 경로를 사용하면 오류가 나타날수 있으니, 상대경로를 사용해야한다.
2. **환경 호환성**
    1. target 옵션을 사용하여 컴파일된 코드의 ECMAScript버전을 지정할수 있다.
    2. 프로젝트가 구형 브라우저에서도 동작해야한다면 target 옵션을 es5 또는 es6로 설정해야한다.
3. **타입 검사**
    1. strict 옵션을 true로 설정하면 하위의 모든 타입검사 옵션을 활성화한다.
    2. 코드의 품질을 향상시키지만 일부 경우에는 불필요한 경고를 발생 시킬수 있으니, 적절히 설정해야한다.
4. **설정 상속**
    1. extends 옵션을 사용하여 다른 tsconfig파일의 설정을 상속받을수있다.
    2. 여러 프로젝트에서 공통설정을 재사용 할수있지만, 순환참조는 허용되지 않는다
5. **모듈 해석**
    1. moduleResolution 옵션은 모듈을 어떻게 해석할지 결정한다.
    2. node/ classic중 하나를 선택할수 있고, 대부분 node를 사용한다
6. **출력 디렉토리**
    1. outDir 옵션을 사용하여 컴파일된 파일이 내보내질 디렉토리를 지정하는데 기본적으로 프로젝트의 루트 디렉토리를 기준으로 한다.
