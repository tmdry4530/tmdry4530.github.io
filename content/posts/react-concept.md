# React란?


React는 사용자 인터페이스를 구축하기 위한 JavaScript 라이브러리. Facebook에서 개발하고, 선언적, 효율적, 유연한 방식으로 대규모 애플리케이션의 데이터 변경에 대응하기 위해 설계.


## React의 등장 배경

1. **프론트엔드 환경의 변화**: 안정적이고 신뢰할 수 있는 솔루션이 필요한 시점에 React 탄생.
2. **jQuery의 한계 극복**: 크로스 브라우징 문제 해결에 기여했으나, 대규모 애플리케이션에는 유지보수 및 성능 문제 발생.
3. **SPA(Single Page Application)의 대중화**: 페이지 새로 고침 없이 동적인 웹 경험 제공하는 SPA의 등장으로 새로운 웹 애플리케이션 개발 방식 필요성 ↑

## 프레임워크와 라이브러리의 특징

- **프레임워크**: 특정 구조와 패턴을 강제하며 애플리케이션 기본 골격 제공.
- **라이브러리**: 선택적 사용 가능한 도구 모음. React는 라이브러리로 분류되며, 원하는 부분에만 적용 가능.

### 프론트엔드 개발의 주요 기술

- **Angular**: 엔터프라이즈 개발에 적합한 Google 지원 포괄적 프레임워크.
- **Vue**: 가볍고 사용자 친화적, 강력한 프로그레시브 프레임워크.
- **React**: 유연성과 재사용성이 뛰어난 Facebook 지원 컴포넌트 기반 라이브러리.

### React의 핵심 개념

1. **단방향 데이터 흐름**: 상위에서 하위 컴포넌트로의 데이터 흐름으로 상태 관리 용이.
2. **컴포넌트 기반 아키텍처**: 독립적인 컴포넌트로 사용자 인터페이스 구성, 재사용성 및 유지보수 용이.
3. **가상 DOM (Virtual DOM)**: 실제 DOM의 경량화 복사본. 변경사항 먼저 가상 DOM에 적용 후 실제 DOM에 반영.
4. **Props와 State**: Props는 컴포넌트 간 데이터 전달 방식. State는 컴포넌트 내부 데이터 관리.
5. **JSX (JavaScript XML)**: HTML과 유사한 구문 사용으로 컴포넌트 구조 쉽게 정의. Babel을 통해 JavaScript 코드로 변환.

### SPA와 React


React는 SPA 개발에 이상적. 사용자와의 상호작용이 많은 동적 웹 애플리케이션 개발에 적합하며, 페이지 새로 고침 없이 부드러운 사용자 경험 제공. 효율적인 데이터 관리 및 빠른 렌더링 지원.
