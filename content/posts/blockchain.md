# 블록체인


## 블록이란?


블록체인에서의 기본 단위이다. 블록은 트랜잭션, 해시, 이전블록의 해시를 포함하고, 새로운 블록이 생성될때마다 이전 블록의 해시가 새로운 블록에 포함되서 블록들이 연결된다

- **트랜잭션 :** 사용자의 송금 및 거래 내역
- **해시 :** 데이터를 64자의 문자열로 매핑하는 함수
    - 데이터의 무결성을 보호하고 검증하는데 사용된다.
- **이전 블록의 해시 :** 해당 블록이 생성되기 전의 블록의 해시값
    - 블록체인의 무결성과 보안을 보장하기 위해 사용된다.

## P2P (Peer to Peer)


중앙서버 없이 컴퓨터들이 서로 직접연결되어 정보를 주고받는 방식이다.


이 방식에서 모든 컴퓨터는 클라이언트와 서버의 역할을 동시에 수행한다.


## 원장 관리


원장은 트랜잭션의 이력을 저장하는 데이터베이스로 볼수있고, 분산네트워크에 참여하는 모든 노드에 저장되며, 이를 통해 모든 참여자가 트랜잭션을 검증하고 승인할수있다.

## Longest chain rule


이 규칙은 탈중앙화 네트워크에서 체인이 여러개로 분리 될수있다는것을 고려한 것이다.


가끔 두개이상의 노드가 동시에 새로운 블록을 생성할수있는데, 이 경우에 두개 이상의 블록체인으로 분리된다. 이럴때에 어떤 체인을 유효한 체인으로 인식할지 결정하는 규칙이다.


## 블록체인 4대 요소


### 블록의 트랜잭션


트랜잭션은 사용자의 송금 내역을 포함하며, 이러한 송금 내역들은 안정성을 보장하기 위해 하나의 블록에 포함됩니다. 즉, 블록에 포함된 트랜잭션은 안정적인 데이터를 보장한다. (POW,POS,POA)


### 분산 네트워크


P2P구조를 가진 네트워크. 사용자가 원하는 시점에 네트워크에 참여하거나 나갈수있다.


### 암호화


암호화는 거래의 위변조를 방지하고, 그것을 증명하는 역할을 한다.


### 합의 알고리즘


분산네트워크에서 중앙화된 기관이 없어도, 모든 사용사용자들이 인정 할수있는 하나의 거래장부를 만들어주는 기술이다. 네트워크의 안정성을 보장하며, 하나의 체인을 유지하는 중요한 역할을 한다.


## 블록의 구조


블록은 헤더와 바디로 구분되고, 헤더에는 블록에 데한 메타데이터가 포함되있고 바디에는 트랜잭션정보를 담고있다.


### 블록의 헤더

- 버전: 블록의 버전 정보
- 이전 해시: 이전 블록의 해시 값
- 높이: 블록의 위치 정보
- 생성 시간: 블록의 생성 시간 정보(타임스탬프)
- 블록 해시: 블록의 해시 값
- 머클루트: 블록의 바디의 내용을 해싱한 값. 하나의 해시값이 남을때까지 더하고 해싱작업을 반복한다.
- 블록 난이도: 블록을 채굴하기 위해 충족해야 하는 해시 값의 난이도를 나타낸
- 논스: 블록 채굴을 위한 연산 시도 횟수

### 블록의 바디

- 트랜잭션의 수 : 블록에 포함된 트랜잭션의 수
- 트랜잭션 정보 : 송금자, 수취인, 금액, 서명 등의 정보를 포함한다.

최초의 블록 구


```shell
const block = {
  version: "1.0.0",
  height: 0,
  timestamp: Date.now(),
  previousHash: "0".repeat(64),
  hash: "0".repeat(64),
  merkleRoot: "0".repeat(64),
  nonce: 0,
  difficulty: 0,
  data: [
    "The Times 03/Jan/2009 Chancellor on brink of second bailout for banks",
  ],
};
```


## 합의 알고리즘 종류


### POW (Proof of Work)

- **개념 :** 복잡한 수학문제를 풀어서 새로운 블록을 생성하는 방식
- **장점 :** 높은 보안성, 분산성
- **단점 :** 높은 에너지 소비, 느린 처리 속도

### POS (Proof of Stake)

- **개념 :** 네트워크에 스테이킹한 토큰의 양에 따라 새로운 블록을 생성할 확률이 결정되는 방식
- **장점 :** 낮은 에너지 소비, 빠른 처리 속도
- **단점 :** 보안성이 POW보다 낮다, 고래(대량 홀더) 우대 현상 발생 가능성

### POA (Proof of Authority)

- **개념 :** 네트워크의 권한을 가진 노드들이 새로운 블록을 생성하는 방식
- **장점 :** 높은 처리속도, 낮은 에너지 소비
- **단점 :** 중앙화 구조, 보안성이 다른 증명방식보다 낮다

해당 방식 이외에도 **PBFT, DPoS, LPoS** 같은 방식이 있다.
